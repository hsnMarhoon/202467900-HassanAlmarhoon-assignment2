Hotel Management Database System

Designed and implemented a relational database system to organize complex hotel operations. The system handles interconnected data including guest details, room types, availability, bookings, payments, and services—all in a unified, efficient structure.

  • Core Focus: Relational design, normalization, and data integrity
  • Key Features: Primary & foreign keys, constraints, optimized indexes
  • Problem Solved: Eliminated duplicate bookings, inconsistent records, and slow response times
  • Impact: Faster room availability queries, accurate reservations, and reliable billing

Game Asset Reverse Engineering

Reverse-engineered proprietary game assets by analyzing binary file formats and reconstructing visual data. Extracted and optimized sprite sheets, rebuilt individual frames, and recovered animation sets and color palettes from compiled game files.

  • Scope: Header parsing, file format analysis, data extraction
  • Achievements: Optimized sprite sheet reconstruction with frame-by-frame accuracy
  • Technical Skills: Binary file handling, animation frame sequencing, color palette recovery
  • Result: Successfully extracted complete animation sets and visual assets
